# Homebrew Tap

Custom Homebrew tap for [dictait](https://github.com/trahloff/dictait) and CamControl.

## Install

```bash
brew tap trahloff/tap
brew install --cask dictait-mac
brew install --cask camcontrol
```

## Available Casks

| Cask | Description |
|------|-------------|
| `dictait-mac` | Global dictation for macOS with AI-powered transcription |
| `camcontrol` | Face-priority exposure and Key Light control for Insta360 Link 2/2C |
